직접 돌려보기

명령어 두 줄이면 파이프라인 전체가 떠요. 드론부터 게이트웨이·프록시·코어·모델 API·두 화면까지 전부 실제 코드로 돌아가요.

시작하기

npm install
npm run demo

그러면 이 주소들이 열려요.

접속 주소
화면 주소
관제탑 http://localhost:8080/res/static/control.html
현황판 http://localhost:8090/res/static/status.html
드론 패널 http://localhost:5173/src/skylens_drone/index.html

/는 아무것도 안 띄워요. 랜딩 페이지를 자동으로 서빙하지 않아요. 위 주소를 그대로 쳐 주세요.

데모는 이렇게 흘러가요

  1. 시작하면 멈춰 있어요

    아직 아무 일도 일어나지 않아요. 경로가 지정되기를 기다리는 상태예요.

  2. 관제탑에서 경로를 지정해요

    경로 계획 · ROUTE에서 웨이포인트를 찍고 배정하면 "태스크 지정 완료"로 바뀌어요. 드론이 현장에 도착해 연결되면 작업이 시작된다는 안내가 떠요.

  3. 약 10초 뒤 드론이 붙어요

    "드론 연결됨" 알림이 뜨고 주행이 시작돼요. 지정한 경로를 왕복해요. 드론은 이동하는 동안에도 위치를 계속 보내지만, 코어는 도착 인사(drone-hello)를 보낸 드론만 도착으로 세요.

  4. 지나간 구간부터 현황판이 채워져요

    드론이 한 구간을 통과할 때마다 그 구간의 수준 1이 확정되고, 이어서 수준이 올라가요. 좌측 상단 패널에서 구간별 현재 수준을 볼 수 있어요.

데모에서 바뀌는 건 두 가지뿐이에요

컴포넌트는 전부 실제 코드예요. 한 대의 컴퓨터에서 재현할 수 없는 것만 바꿔 놨어요.

실운영과 데모의 차이
항목 실운영 데모
드론 촬영 기체 카메라 → H.265 실시간 인코딩 미리 인코딩해 둔 영상 파일
3D 복원 GPU 서버에서 gsplat 학습 미리 만들어 둔 구간 × 수준 자산

나머지는 전부 실제 경로예요. 드론이 게이트웨이에 붙고, 프록시가 코어로 중계하고, 코어가 모델 API에 잡을 발행하고, 현황판이 릴레이를 통해 받아요.

데모 자산이 없으면 현황판은 단일 장면 스트림으로 알아서 돌아가요. 딜레이 패턴만 안 보이고 나머지는 그대로예요.

주소 뒤에 붙이는 옵션

주소 끝에 ?옵션을 붙이면 동작을 바꿀 수 있어요.

자주 쓰는 옵션
옵션 하는 일
?demo 자동 데모로 돌아가요
?room=<이름> 두 화면을 같은 방 이름으로 열면 서로 연결돼요
?splat=off|demo|cdn|light|<url> 3D 장면 자산을 어디서 가져올지 정해요
?delay=off 딜레이 패턴을 끄고 장면 하나로 봐요
?reveal=on|off 장면이 드러나는 마스크를 켜고 꺼요
?spin=off 카메라 자동 회전을 꺼요
?up=<preset|euler> 3D 장면의 위쪽 방향을 맞춰요
?level=on 장면 수평을 자동으로 맞춰요 (PCA)

실지형 지도 옵션

?map을 쓸 때 함께 쓰는 옵션
옵션 하는 일
?map 실지형 씬을 켜요. ?map=uljin|gangneung|서,남,동,북으로 지역을 고를 수 있어요
?tex=sat|off 지형 위에 위성 영상을 입힐지 정해요
?drone=<n> 드론 아이콘 크기예요. 기본값은 0.15
?ring=off 씬 바깥의 배경 지형 링을 꺼요
?bld=off 3D 건물을 안 그려요

VWorld 키 설정

위성 영상과 건물 데이터는 VWorld 인증 키가 필요해요. 키는 저장소 안이 아니라 저장소의 부모 폴더에 둬요. 

# 저장소 바로 바깥 디렉터리에서
cat > .env.vworld << EOF
VWORLD_KEY=<vworld.kr에서 발급한 인증키>
VWORLD_DOMAIN=http://localhost:5173
EOF

키가 없어도 괜찮아요. 지형과 건물만 안 그려지고 나머지는 그대로 돌아가요.

키는 개발 서버의 프록시가 서버 쪽에서만 끼워 넣어요. 프론트엔드 번들에는 절대 들어가지 않아요.

명령어 전체

TypeScript 쪽
명령 하는 일
npm run demo 전 컴포넌트를 데모 모드로 조립해서 띄워요
npm run dev Vite 개발 서버만 띄워요 (HMR, LAN 노출)
npm run core 등 컴포넌트를 하나씩 띄워요. core · client · gateway · proxy · drone · model
npm run build 타입체크하고 빌드해요
npm test Playwright E2E를 돌려요. npm run test:headed면 브라우저가 보여요
npm run demo:clean 데모로 띄운 프로세스를 정리해요
Python 쪽: 의존성은 uv로 관리해요
명령 하는 일
uv sync .venv/를 만들고 패키지를 설치해요
uv run pytest 테스트를 돌려요
uv run ruff check src/ 린트를 돌려요
uv run jupyter lab 학습 노트북(train.ipynb)을 열어요

torch는 PyPI에서 안 받아요. CUDA 12.8 인덱스에서 받도록 pyproject.toml에 지정해 뒀어요. Python은 3.11 이상 3.14 미만이고, 기준 버전은 3.13이에요.

두 대로 나눠서 보고 싶다면

관제탑과 현황판은 각자 다른 컴퓨터에서 전체화면으로 띄우는 걸 전제로 만들었어요. npm run dev는 LAN에 열려 있으니까 같은 네트워크의 다른 컴퓨터에서 http://<IP>:5173/res/static/control.html?room=demo 같은 주소로 접속하면 돼요.

두 화면의 room 값만 같으면 연결돼요. &demo를 붙이면 자동 데모로 돌아가요.
