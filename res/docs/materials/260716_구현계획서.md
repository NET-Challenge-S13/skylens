## Ⅰ. 기획안 내용

### 1. 개요

본 과제는 재난 현장에 투입된 다수 드론의 영상을 KOREN 고속망으로 Core HPC에 실시간 전송하여, 3D Gaussian Splatting으로 현장을 3D 복원하고, 동일 영상에 RGB+열화상 4채널 세그멘테이션 AI를 적용해 붕괴/화재 등 위험구역과 요구조자(사람)를 자동 감지하는 시스템(이하 'SkyLens')이다.

2D 감지 결과는 Depth Map 레이캐스팅으로 3D 좌표에 투영되며, 현장 인근 Edge VM이 저지연으로 서빙하는 3D 상황판에서 지휘관이 위험구역과 인명 위치를 한눈에 확인하고 진입 동선을 판단할 수 있다. 단일 드론/사후 처리에 머문 기존 방식과 달리, 멀티드론/준실시간/연구망 분산 AI를 결합한 것이 본 과제의 핵심이다.

### 2. 개발 목적 및 필요성

**(1) 소방드론은 빠르게 확산되고 있으며, AI 고도화가 다음 단계다.**
소방드론 출동 건수는 2019년 738건에서 2024년 4,600건으로 5년 만에 6배 이상 급증했고, 전국 소방관서에 554대가 배치되어 재난 현장의 핵심 장비로 자리잡았다. 현재는 실시간 영상 중계가 주된 역할이며, 소방청의 '소방드론 협의회' 신설과 충남도의 "드론영상 AI 분석시스템 구축" 추진은 AI 기반 분석으로의 전환이 본격화되고 있음을 보여준다.

**(2) 3D 현장 인지는 대원 안전과 직결된다.**
재난 현장에서 건물 내부 구조나 붕괴 징후를 사전에 파악하는 것은 대원의 안전한 진입 판단에 핵심적이다. 진입 전 현장을 3D로 복원하고 위험 요소를 AI로 감지할 수 있다면, 지휘관의 상황 판단 정확도와 대응 속도를 크게 높일 수 있다.

**(3) 멀티모달 통합 인지 드론 AI 플랫폼의 기술적 토대가 마련되고 있다.**
KISTI는 재난 상황의 객체 탐지에 영상·음성·문자 인지를 통합한 모델이 필요하다고 제시하였고, 2024년 AI 기반 드론 소음 억제 기술과 2025년 SAR용 오디오 데이터셋(DroneAudioset) 공개로 소리 기반 탐지의 기술적 기반도 갖춰지고 있다. 이러한 요소 기술들을 하나의 플랫폼으로 통합할 시점이 된 것이다.

### 3. 세부 개발 내용 및 범위, 예상 결과물

#### ① 멀티드론 분할 탐색 + 실시간 3D 복원

2~3대 드론이 구역(A/B/C)을 나눠 동시 촬영하고, Core HPC에서 GLOMAP/COLMAP 포즈 추정 → gsplat(3DGS) GPU 학습 → Open3D ICP 멀티드론 융합 순으로 복원한다.

3DGS는 여러 시점 영상과 카메라 포즈로 3D 가우시안을 역렌더링 최적화하는 per-scene 과정이며, 다시점이 필수이므로 멀티드론이 기하학적으로 정당하다. RTK/IMU 포즈를 prior로 활용해 SfM 부담을 줄인다.

프레임 단위 완전 실시간 대신 30초 주기 배치(준실시간)로 모델을 갱신하며, 동일 영역의 변경분만 반영하는 증분 갱신 방식을 적용한다.

> [그림 2. SkyLens 전체 파이프라인]

#### ② AI 위험구역/사람 감지 (Early Fusion)

RGB(3채널) + 열화상(1채널) = 4채널을 입력단에서 결합하여, AI Hub 야간 사고 대응 계열 RGB+열화상 데이터셋으로 처음부터 학습한다. 가시광이 약한 야간/연기 상황을 열화상이 보완한다.

구조는 하나의 공유 백본 + 두 헤드로 구성한다. 인코더 4스테이지 → TransUNet 보틀넥(Multi-Head Self-Attention) → 디코더 4스테이지를 거친 뒤, (a) 세그멘테이션 헤드가 위험구역을 영역 마스크(stuff)로, (b) 인스턴스 헤드가 사람을 점 위치(u,v) + confidence로 출력한다.

위험구역(불/붕괴)은 형태가 불명확한 영역이므로 객체 박스가 아닌 영역 분할이 적합하고, 사람은 잔해 속 소형 객체이자 이후 3D 투영 단계에서 점+confidence로 다뤄야 하므로 인스턴스로 분리한다.

> [그림 3. 영상 AI 모델 상세 구조 (4채널 Early Fusion + 듀얼 헤드)]

#### ③ 2D → 3D 결합 (Depth Map 레이캐스팅)

3DGS에 직접 레이캐스팅하지 않고, 복원된 3DGS를 탐지 프레임의 드론 포즈로 렌더할 때 나오는 Depth Map(Z-Buffer)을 역참조한다. 깊이는 드론 센서가 아니라 렌더링 부산물이다.

핀홀 역투영으로 카메라 로컬 좌표를 구한 뒤 포즈 [R|t]로 세계좌표로 변환한다.

탐지 좌표 (u,v)가 찍힌 카메라 포즈와 동일 시점으로 3DGS를 렌더해야 RGB/깊이맵/(u,v)가 픽셀 1:1 정합되므로, 포즈가 필수 입력이다.

마커는 Core HPC에서 세계좌표로 1회 고정(시점 무관)되어 .splat + 마커로 저장되고, Edge 뷰어는 받아서 표시만 한다.

보정: 멀티드론 삼각측량(드론 A/B의 Ray 교차로 노이즈 감소), 지표면 강제 투영(마커가 공중에 뜨는 버그 방지)

#### ④ 저지연 3D 상황판 배포

Core 산출물(.splat + 마커)을 rsync delta 증분 동기화로 사고 인근 Edge VM(GPS 기반 캐싱/라우팅)에 전달한다.

Edge VM이 웹 3D 뷰어(Three.js GaussianSplats3D)를 저지연 서빙하고, 지휘관 단말은 WebRTC로 받아 회전/이동/거리 측정을 수행한다.

### 4. 특징 (동일·유사 기술에 대한 차별성, 독창성, 혁신성 등)

**(1) 멀티드론 + 준실시간 처리**
- 기존: 단일 드론 촬영 → 사후 3D 복원(수 시간 소요)
- 본 과제: 다수 드론 동시 촬영 → KOREN 고속망 실시간 전송 → 준실시간 3D 복원

**(2) RGB+열화상 4채널 융합 AI**
- 기존 재난 감지 AI는 RGB 또는 열화상 단일 모달리티에 의존
- 본 과제는 4채널(RGB 3ch + 열화상 1ch) 입력으로 가시광/열 정보를 동시에 활용하여 연기/어둠 속 요구조자 감지 성능을 향상

**(3) 연구망 분산 AI 파이프라인**
- Core HPC(3D 복원 + AI 추론) → Edge VM(저지연 서빙)으로 역할을 분산
- KOREN 연구망의 고대역/저지연 특성을 활용한 실시간 파이프라인 구성

**(4) 2D 감지 → 3D 공간 매핑**
- 단순 2D 바운딩 박스가 아닌, Depth Map 레이캐스팅으로 3D 좌표에 투영
- 지휘관이 실제 공간에서의 위치/거리/진입 경로를 직관적으로 판단 가능

## Ⅱ. 아이디어 구현 계획

### 1. 아이디어의 세부 구현 계획 및 적용

#### 가. 하드웨어 부분

- **드론**: RGB 카메라 + 열화상 카메라 탑재 드론 3대 이상
- **Core HPC**: KOREN 접속 노드에 위치한 GPU 서버, 3D Gaussian Splatting 및 AI 추론 수행
- **Edge VM**: 현장 인근 KOREN 엣지 노드의 VM 인스턴스, 3D 상황판 서빙 전담
- **네트워크**: KOREN 고속망 활용, 드론 → Core HPC → Edge VM 간 데이터 흐름

#### 나. 소프트웨어 부분

- **영상 전송**: GStreamer/FFmpeg 기반 RTSP/SRT 스트리밍, 드론 간 타임스탬프 동기화
- **3D 복원**: 3D Gaussian Splatting, 멀티뷰 입력으로 점진적 모델 갱신
- **AI 감지**: PyTorch 기반 4채널 세그멘테이션 모델(UNet/TransUNet), TensorRT 최적화 추론
- **2D → 3D 투영**: Depth Map 추출 후 카메라 내/외부 파라미터 기반 레이캐스팅
- **3D 상황판**: Three.js/Gaussian Splatting 웹 뷰어, WebSocket 기반 실시간 데이터 수신

### 2. KOREN 연동 및 활용 방안

본 과제에서 KOREN망은 시스템 전체 파이프라인의 핵심 인프라로, 단순 데이터 전송을 넘어 분산 AI 처리의 기반이 된다.

**(1) 멀티드론 영상의 실시간 전송**
- 다수 드론이 촬영한 고해상도 RGB+열화상 영상을 KOREN 고속망(10Gbps급)으로 Core HPC에 실시간 전송
- 드론 1대당 약 50~100Mbps(4K RGB + 열화상) 스트림 × 3대 이상 = 수백 Mbps급 동시 전송 필요
- 일반 인터넷망으로는 대역폭/지연 측면에서 불가능한 수준이며, KOREN의 전용 고속 경로가 필수

**(2) Core HPC ↔ Edge VM 간 분산 처리**
- Core HPC에서 수행한 3D 모델 데이터 및 AI 감지 결과를 KOREN망을 통해 Edge VM으로 저지연 전달
- 3D Gaussian Splatting 모델(수십~수백 MB)을 수 초 내 전송하여 Edge에서 즉시 렌더링
- Core(연산 집약) → Edge(서빙 집약) 역할 분리가 KOREN의 저지연/고대역 특성으로 가능

**(3) KOREN 인프라 활용 계획**
- **Core HPC**: KOREN 접속기관의 GPU 서버 자원 활용 (3D 복원 + AI 추론)
- **Edge VM**: 현장 인근 KOREN 엣지 노드의 VM 할당 (3D 상황판 저지연 서빙)
- **네트워크**: KOREN SDN 기반 QoS 설정으로 영상 트래픽의 우선순위 보장

**(4) KOREN망 없이는 불가능한 이유**
- 멀티드론 고해상도 영상의 동시 실시간 전송은 일반 인터넷의 대역폭/안정성으로 불가
- Core HPC → Edge VM 간 3D 모델 전송의 저지연 요구사항(수백 ms 이내)은 전용망에서만 충족 가능
- 연구망의 안정적 QoS 보장이 재난 상황의 미션 크리티컬 데이터 흐름에 필수

### 3. 결과물의 통합 및 시험/검증 계획

**(1) 단위 모듈 검증**
- 영상 전송: 드론 3대 동시 스트리밍 시 KOREN망 대역폭/지연 측정
- 3D 복원: 3D Gaussian Splatting 품질(PSNR/SSIM) 및 갱신 주기 측정
- AI 감지: 위험구역/사람 감지 정확도(mIoU, F1-score) 평가
- 2D → 3D 투영: 투영 좌표의 실제 위치 대비 오차(m 단위) 측정

**(2) 파이프라인 통합 검증**
- 드론 촬영 → KOREN 전송 → HPC 처리 → Edge 서빙까지 End-to-End 지연시간 측정
- 목표: 촬영 시점 ~ 상황판 반영까지 30초 이내

**(3) 시나리오 기반 시험**
- 모의 재난 현장(건물 모형 + 열원 배치)에서 실제 드론 운용 테스트

### 5. 기술 구현에 따른 기대효과

- **재난 대응 골든타임 확보**: 현장 3D 복원 및 위험 감지를 준실시간으로 수행하여 지휘관의 의사결정 시간을 단축
- **인명 구조 효율 향상**: AI 기반 요구조자 자동 감지로 수색 누락을 방지하고, 3D 공간 좌표 제공으로 정확한 위치 파악 가능
- **지휘관 상황인식 강화**: 2D 영상 대비 3D 상황판을 통해 현장의 공간 구조/위험도/인명 분포를 직관적으로 파악
- **KOREN 연구망 활용 모델 제시**: 멀티드론 실시간 전송 + Core-Edge 분산 AI 처리라는 연구망 고유의 활용 사례를 확립
- **확장 가능성**: 소리 기반 생존자 탐지, 자율 드론 경로 계획 등 후속 과제로 확장 가능한 플랫폼 구축

## Ⅲ. 연구 개발비 사용 계획

> pyhwpx로 원본을 직접 열어 확인한 결과, 이 장은 실제로 비어 있다 — 저자가 작성하지 않은 상태다. "연구 개발비 사용 계획" 표제는 문서 앞부분 목차(TOC) 미리보기 표 안에만 한 번 등장하며, 바로 뒤에 빈 문단 4개가 이어지고 표가 닫힌다. 본문에는 이 표제가 다시 나타나지 않고, 실제 서술은 Ⅱ-5. 기술 구현에 따른 기대효과에서 끝난다. 문서 내 이미지 4개(서명 도장 1 + 아키텍처 다이어그램 3)는 모두 Ⅰ·Ⅱ장에 위치하며 Ⅲ장 근처에는 없다. 즉 변환 누락이 아니라 원본 자체가 미작성 상태다.
